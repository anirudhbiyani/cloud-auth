# cloud-auth

**Unified cross-cloud authentication lifecycle management.** A Go library and CLI that sets up, validates, audits, and uses workload identity federation between AWS, GCP, Azure, Kubernetes, GitHub Actions, Anthropic, and OpenAI, with no long-lived credentials anywhere.
